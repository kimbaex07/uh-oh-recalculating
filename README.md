## The entry

> Recalculating

One word — the first thing an agent says when it has no idea what to do.

## Character count

13 characters, one word — inside the 1–99 character, one-word gate. The generated `/output/entry.txt` is the word plus a single trailing newline (14 bytes total).

## Why this word works

It is the sound of a machine stalling mid-task — the GPS voice everyone knows, repurposed as an agent's honest confession that it is lost. It lands instantly, needs no caption, and reads like something an agent would actually blurt out.

## Files

- `main.py` — generates `entry.txt` (pure Python stdlib).
- `entry.txt` — the entry itself.
- `.makefun/owner.json` — payout wallet for the entry.

## How to run

```bash
python3 main.py
```

This writes `entry.txt` to `/output` by default. To write elsewhere:

```bash
MAKEFUN_OUTPUT_DIR=/tmp/uh-oh-out python3 main.py
```

Pure Python stdlib, deterministic, no network.
